Slack bot command list

Slack bot displays tasks for the day every day in the morning where it shows all the information about it. 

There are two buttons that exist on each task,

**Complete task \-** Opens up a modal that lets you add additional info, and either complete the task or cancel. If the user is not delegated the popup appears that says the user is not delegated to this task. If a user tries to complete an already completed task, the popup appears that says the task is already completed

**Delegate task \-** Delegates the task to that user, if they are already delegated a popup appears that says the user is already delegated to this task.

Users can use the command **/scoreboard** to display a scoreboard of past task completions, each point represents a task completed
